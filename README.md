# Daily Coding Journey

This repository contains my daily coding practice and tracks my progress from programming basics to advanced problem-solving and Data Structures & Algorithms.

## Goal

* Code consistently every day
* Build strong programming fundamentals
* Improve problem-solving skills
* Learn Data Structures & Algorithms step by step
* Practice Git and GitHub through daily commits
* Keep my solutions organized and easy to understand
* Share my learning journey with others

The repository will gradually move from **basic concepts → problem solving → data structures → algorithms → advanced problems**.

## Solution Format

For each problem, I try to include:

* Problem name and source
* My approach
* Solution code
* Time complexity
* Space complexity
* Useful comments
* What I learned

## Languages

Java

## Why This Repository?

The main purpose of this repository is consistency.

Instead of only solving problems, I want to document my progress, understand my solutions, improve my coding habits, and become more comfortable using Git and GitHub.

> Consistency over perfection.
